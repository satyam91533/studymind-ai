# StudyMind AI

**Learn Smarter. Prepare Better. Achieve More.**

StudyMind AI is a cross-platform learning assistant for learners from Class 6 to postgraduate level and competitive examinations. The project is being built in practical, testable stages.

## Product goals
- Hindi and English learning experience first; more languages can follow.
- Class 6–12, undergraduate, postgraduate and competitive-exam study paths.
- AI tutor, notes, MCQs, mock tests, PDF learning, flashcards and study planning.
- Verified admin-managed syllabuses, AI-suggested (clearly unverified) structures, and student-uploaded syllabuses.
- Free-first launch. Premium subscriptions are intentionally deferred.
- Shared account and backend across web, Android, iOS and Windows.

## Current development stage
This repository starts with the responsive React + TypeScript web foundation. The Django REST API is scaffolded separately. AI services must be connected through secure server-side environment variables; never put provider API keys in frontend code.

## Technology
- Frontend: React, TypeScript, Vite
- Mobile packaging: Capacitor (planned)
- Windows desktop packaging: Tauri (planned)
- Backend: Django + Django REST Framework
- Database: PostgreSQL in deployment; SQLite for local development

## Run the frontend
```bash
npm install
npm run dev
```

## Run the backend
```bash
cd backend
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

## Configuration
Create a local `.env` from `.env.example`. Do not commit secrets. AI requests, authentication, file processing and usage limits belong on the backend.

## Roadmap
1. Responsive product foundation and navigation
2. Django authentication, student profile and syllabus library
3. AI tutor, notes and MCQ generation with server-side limits
4. Timed mock tests, PDF learning and progress tracking
5. Admin tools, privacy/security hardening and deployment
6. Android/iOS/Windows packaging and device testing

## Important
Syllabus suggestions generated by AI are not official until reviewed against the relevant board/university source. The app is an educational aid and should not present generated answers as guaranteed or official.
